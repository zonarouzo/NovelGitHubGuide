小説管理リポジトリの作成

小説の原稿や設定資料をしまう、あなた専用の「保管場所」を作ります。

リポジトリとは

リポジトリは、GitHub の中にあるひとつの「保管箱」のようなものです。フォルダやファイルを入れておくことができ、中身を変更するたびに履歴が記録されます。

このサイトでは、1つのリポジトリに、ひとつの作品世界（本編とスピンオフ）をまとめて保管します。

テンプレートとは

テンプレートは、小説管理に必要なフォルダや、Claude 用のルール（CLAUDE.md）があらかじめ入った「ひな形」です。これをコピーして、自分のリポジトリを作ります。中身は次のような構成です（予定）。

フォルダ・ファイル入れるもの
settings/全作品に共通する設定資料（キャラクター・世界観・年表・文体ルールなど）。中に style_samples/（文体の手本にする過去作）
novels/本編の完成原稿。中に drafts/（第一稿）と plots/（プロット）
spinoffs/スピンオフ。作品ごとにフォルダを作り、それぞれに完成原稿・drafts/・plots/・必要なら settings/
CLAUDE.mdClaude が守る作業ルール
README.md使い方の説明

原稿は .txt（テキストファイル）、設定資料やプロットは .md（マークダウン）という形式で保存されます。

テンプレートからコピーする

  1. GitHub にログインした状態で、上のボタンからテンプレートのページを開きます。

  2. ファイル一覧の上にある Use this template をクリックし、Create a new repository を選びます。

  3. Owner（持ち主）が自分のユーザー名になっていることを確認します。

  4. Repository name（リポジトリの名前）を入力します。決め方は下の「名前の決め方」を参照してください。

  5. 公開範囲で Private を選びます。ここがいちばん大切です。

  6. Include all branches というチェックは、付けずにそのままにします。

  7. Create repository（または Create repository from template）をクリックします。

手順は GitHub 公式ドキュメント「テンプレートからリポジトリを作成する ↗」にもとづいています。ボタンの表記は変わることがあります。

名前の決め方

  • 半角英数字とハイフン（-）で付けるのがおすすめです。日本語や空白は避けましょう。
  • 作品や作品世界がわかる名前にしておくと、あとで見分けやすくなります。
  • 名前はあとから変更することもできます。
よい例避けたい例
my-novel
hoshiyomi-novel
fantasy-series		私の小説（日本語）
my novel（空白入り）

Private を選ぶ理由

GitHub のリポジトリには、Public（公開）とPrivate（非公開）があります。

種類見られる人
Public（公開）インターネット上の誰でも、原稿や設定を読めます
Private（非公開）あなたと、あなたが許可した人（と連携したサービス）だけ

⚠️ 必ず Private を選んでください

Public にすると、未発表の原稿やアイデアが誰でも読める状態になります。作成後に Public になっていることに気づいた場合は、リポジトリの Settings の一番下にある「Danger Zone」から公開範囲を変更できます。

作成後の確認

作成が終わると、自分のリポジトリのページが表示されます。次の点を確認してください。

  1. リポジトリ名の横に 「Private」という表示があること。

  2. ファイル一覧に CLAUDE.md、README.md、settings、novels、spinoffs があること。

  3. ページのアドレス（URL）をブックマークしておくこと。
    例：https://github.com/あなたのユーザー名/my-novel

📝 サンプルの作品について

テンプレートには、使い方の例として架空のサンプル作品が入っています。サンプルは、ステップ4「小説の初期設定」で Claude に頼んで削除します。自分で消す必要はありません。
