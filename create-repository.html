小説管理リポジトリの作成

このページでやること

  1. テンプレートをコピーして、自分専用のリポジトリを作る
  2. 「Private（非公開）」になっているか確認する

目安：5分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

リポジトリ・テンプレートとは？知っておくと安心

リポジトリは、GitHub の中の「保管箱」です。1つのリポジトリに、ひとつの作品世界（本編とスピンオフ）をまとめて保管します。

テンプレートは、小説管理に必要なフォルダや Claude 用のルール（CLAUDE.md）が入った「ひな形」です。中身は次の構成です（予定）。

フォルダ・ファイル入れるもの
settings/共通の設定資料（キャラクター・世界観・年表・文体ルール）。中に style_samples/（文体の手本にする過去作）
novels/本編の完成原稿。中に drafts/（第一稿）と plots/（プロット）
spinoffs/スピンオフ。作品ごとのフォルダに、完成原稿・drafts/・plots/・必要なら settings/
CLAUDE.mdClaude が守る作業ルール

原稿は .txt、設定資料やプロットは .md で保存されます。

1. テンプレートからリポジトリを作る

  1. GitHub にログインした状態で、上のボタンからテンプレートのページを開きます。

  2. Use this template → Create a new repository を押します。

  3. Repository name に名前を入力します（例：my-novel）。

    半角英数字とハイフン（-）がおすすめです。日本語や空白は避けましょう。名前はあとから変更できます。

  4. 公開範囲で Private を選びます。

  5. Create repository を押します。

    Include all branches のチェックは付けないままで大丈夫です。ボタンの表記は変わることがあります。手順は GitHub公式ドキュメント ↗ にもとづいています。

必ず「Private（非公開）」を選んでください。

「Public（公開）」にすると、未発表の原稿やアイデアを誰でも読めてしまいます。

2. 作成後の確認

  1. リポジトリ名の横に 「Private」と表示されていることを確認します。

    「Public」になっていたら、リポジトリの Settings の一番下「Danger Zone」から変更できます。

  2. このページのアドレス（URL）をブックマークしておきます。

テンプレートには、使い方の例として架空のサンプル作品が入っています。ステップ4で Claude に削除してもらうので、自分で消す必要はありません。
