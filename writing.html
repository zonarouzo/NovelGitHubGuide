小説の執筆と管理

いつもの流れ

  1. Claude Code を開いて、小説のリポジトリを選ぶ
  2. やりたいことを日本語で頼む（下のプロンプト例を使えます）
  3. 作業が終わったら、main に反映する

このページは、必要なところだけ読めばOKです。小さい文字の「補足」と、▶ で開く説明は読み飛ばしても大丈夫です。

作業が終わったら、毎回 main への反映をしてください。

反映しないと、次に新しい会話を始めたとき、Claude が前回の作業内容を見られないことがあります。

原稿の流れ

① プロット（plots/） → ② 第一稿（drafts/） → ③ 完成原稿（作品フォルダの直下）の順に育てていきます。

テンプレートのルールで守られていること知っておくと安心
  • 完成原稿は、あなたがはっきり指示しない限り変更されません
  • 原稿の削除は、あなたの許可が必要です
  • 第一稿を完成原稿にするのも、あなたの指示があったときだけです
  • 共通設定とスピンオフの設定が食い違っていたら、Claude はあなたに確認します
  • Claude は、既存の原稿・設定・文体サンプルを読んでから執筆します

原稿は .txt、プロットや設定資料は .md で保存されます。

プロンプトの【 】の部分は、自分の内容に書き換えて使ってください。ふだんの言葉で頼んでも大丈夫です。

GitHub の画面で見る

  1. GitHub で小説のリポジトリを開き、見たいファイルをクリックします。
  2. ファイルの上のほうにある History を押すと、変更の一覧が表示されます。

履歴に残るのは、GitHub に保存（反映）された変更です。

作業内容の保存と反映

🛠 今は暫定の手順です

自動で main に反映する仕組みは準備中（未検証）です。今は次の手順で反映してください。

  1. Claude の作業が終わったら、Claude Code の画面で Create PR を押します。

  2. 表示されたリンクから GitHub のページを開き、Merge pull request を押します。

  3. Confirm merge を押します。これで main に反映されます。

なぜこの手順が必要？知っておくと安心

ブラウザ版の Claude Code は、作業内容を GitHub に保存しますが、保存先は多くの場合 main（メインの保存場所）ではなく、その作業専用の「ブランチ（作業用の保存場所）」です。

Create PR で作られる「プルリクエスト（PR）」は、「作業用の保存場所の変更を main に取り込みたい」という申請です。Merge pull request で、その申請を受け入れて main に反映します。くわしくは よくある質問 をご覧ください。
