GitHub とは？知っておくと安心

GitHub（ギットハブ）は、ファイルをインターネット上に保管して、変更の履歴を残しながら管理できるサービスです。本来はプログラム用ですが、文章の管理にも使えます。

このサイトでは、GitHub を原稿や設定資料をしまう「本棚」として使います。Claude はこの本棚から資料を読み、書いた原稿を本棚に戻します。むずかしい操作は Claude に任せるので、覚えなくて大丈夫です。

公式サイト：https://github.com/

1. アカウントを作る

  1. パソコンのブラウザで、GitHub の登録ページを開きます。

    GitHub の登録ページを開く ↗

  2. メールアドレス・パスワード・ユーザー名・国を入力します。

    ユーザー名は半角英数字とハイフン（-）で付けます。ほかの人からも見えるので、本名でなくペンネームのローマ字などがおすすめです。保管場所のアドレス（例：github.com/ユーザー名/my-novel）にも使われます。

    パスワードは、ほかのサービスと同じものを使わないでください。入力項目の順番や見た目は変わることがあります。

  3. ロボットでないことの確認（パズルなど）が出たら、案内に従って答えます。

  4. メールで届いたコードを入力する（またはメール内のリンクを開く）と、登録が完了します。

    利用目的などの質問や有料プランの案内が出たら、スキップして大丈夫です。無料（Free）のままで使えます。

2. メールアドレスを確認する

登録時のメールで確認が終わっていれば、この手順は不要です。確認メールを見逃した場合だけ、次の操作で再送します。

  1. メール設定のページ ↗を開きます。

    画面右上の自分のアイコン → Settings → 左メニューの Emails でも開けます。

  2. Resend verification email を押し、届いたメールのリンクを開きます。

    メールが届かないときは、迷惑メールフォルダを確認してください。

3. 二段階認証を設定する

パスワードに加えて、スマホのアプリに表示される数字でも本人確認をする仕組みです。大切な原稿を守るために設定してください。

  1. スマホに「認証アプリ」を入れます。

    アプリストアで「認証アプリ」「Authenticator」と検索すると見つかります。GitHub は特定のアプリを指定していません。

  2. パスワードと認証の設定ページ ↗を開き、Enable two-factor authentication を押します。

    画面右上の自分のアイコン → Settings → 左メニューの Password and authentication でも開けます。

  3. 画面の QRコードを認証アプリで読み取り、アプリに出た6けたの数字を入力します。

  4. リカバリーコードを Download で保存し、I have saved my recovery codes を押します。

リカバリーコードは、なくさない場所に必ず保管してください。

スマホをなくしたり機種変更したりしたとき、これがないとアカウントに入れなくなるおそれがあります。

二段階認証について、もう少しくわしく知っておくと安心

GitHub は、アカウントの使い方によっては二段階認証の設定を必須にしています。対象になった場合は画面やメールで案内されます。

SMS（ショートメッセージ）で受け取る方法もありますが、GitHub は認証アプリの利用を推奨しています。詳しくは GitHub公式ドキュメント ↗ をご覧ください。

無料プランでできること知っておくと安心

個人向けの無料プラン（GitHub Free）では、非公開（Private）の保管場所を数の制限なく作れます。小説の管理なら無料プランで十分です。一部の高度な機能は有料ですが、このサイトの手順では使いません。

プランの内容は変わることがあります。GitHub公式ドキュメント（GitHubのプラン）↗
