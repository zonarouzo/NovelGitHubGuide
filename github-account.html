GitHubとは

GitHub（ギットハブ）は、ファイルをインターネット上に保管して、変更の履歴を残しながら管理できるサービスです。本来はプログラムを管理するためのものですが、文章の管理にも使えます。

このサイトでは、GitHub を小説の原稿や設定資料をしまっておく「本棚」として使います。Claude はこの本棚から資料を読み、書いた原稿を本棚に戻します。

💡 むずかしい操作は覚えなくて大丈夫

GitHub にはたくさんの機能がありますが、このサイトで使うのはごく一部です。原稿の作成や整理は、Claude に頼んで行います。

公式サイト：https://github.com/

アカウントを作る

  1. パソコンのブラウザで、GitHub の登録ページを開きます。

    GitHub の登録ページを開く ↗

  2. 画面の案内に従って、次のような項目を入力します。

    • メールアドレス：ふだん確認できるもの
    • パスワード：ほかのサービスと同じものは使わず、長くて推測されにくいもの
    • ユーザー名：半角英数字とハイフン（-）で決めます（下の「ユーザー名の決め方」を参照）
    • 国・地域：お住まいの国（日本など）

    入力項目の順番や見た目は、GitHub 側の変更で変わることがあります。画面の表示に合わせて進めてください。

  3. ロボットではないことの確認（簡単なパズルなど）が表示されたら、案内に従って答えます。

  4. 登録したメールアドレスに GitHub から確認のメールが届きます。メールに書かれたコードを画面に入力するか、メール内のリンクを開いて確認を完了します。

  5. 利用目的などの質問が表示された場合は、答えるか、スキップして進みます。有料プランをすすめられても、無料（Free）のままで問題ありません。

ユーザー名の決め方

  • ユーザー名は、GitHub 上であなたを表す名前です。ほかの人からも見えるので、本名を使う必要はありません。
  • あとで作る保管場所のアドレス（URL）にも使われます。例：https://github.com/ユーザー名/my-novel
  • ペンネームをローマ字にしたものなど、覚えやすい名前がおすすめです。

メールアドレスの確認

GitHub のすべての機能を使うには、メールアドレスの確認（認証）が必要です。登録時の確認メールを見逃した場合は、次の方法で再送できます。

  1. GitHub にログインし、画面右上の自分のアイコンをクリックして、Settings（設定）を開きます。

  2. 左側のメニューから Emails を開きます。
    メール設定のページを開く ↗

  3. メールアドレスの下にある Resend verification email をクリックします。

  4. 届いたメールのリンクを開くと、確認が完了します。

📩 メールが届かないときは

迷惑メールフォルダを確認してください。それでも見つからない場合は、少し時間をおいてから再送してください。

二段階認証を設定する

二段階認証（2FA）は、パスワードに加えてスマホのアプリなどに表示される数字でも本人確認をする仕組みです。パスワードが漏れても、ほかの人がログインしにくくなります。大切な原稿を守るため、設定を強くおすすめします。

💡 GitHub からの要求について

GitHub は、アカウントの使い方によっては二段階認証の設定を必須にしています。対象になった場合は画面やメールで案内され、一定の期間内に設定が必要です。早めに設定しておけば安心です。

準備：認証アプリを用意する

スマホに「認証アプリ」（TOTPアプリ）を入れます。GitHub は特定のアプリを指定していません。アプリストアで「認証アプリ」「Authenticator」と検索すると見つかります。

設定の手順

  1. GitHub の画面右上の自分のアイコン → Settings を開きます。

  2. 左側のメニューの「Access」の中にある Password and authentication を開きます。
    このページを直接開く ↗

  3. 「Two-factor authentication」の欄にある Enable two-factor authentication をクリックします。

  4. 画面に表示された QRコードを、スマホの認証アプリで読み取ります。

  5. アプリに表示された6けたの数字を、GitHub の画面に入力します。

  6. リカバリーコード（緊急用のコード）が表示されます。Download を押して保存し、安全な場所に保管してください。

  7. 保存したら I have saved my recovery codes をクリックします。これで設定は完了です。

⚠️ リカバリーコードは必ず保管してください

スマホをなくしたり機種変更したりしたとき、リカバリーコードがないとアカウントに入れなくなるおそれがあります。印刷する、パスワード管理アプリに保存するなど、なくさない方法で保管してください。

SMS（ショートメッセージ）で受け取る方法もありますが、GitHub は認証アプリの利用を推奨しています。詳しくは GitHub公式ドキュメント（二段階認証の設定）↗ をご覧ください。

無料プランでできること

個人向けの無料プラン（GitHub Free）では、非公開（Private）の保管場所を数の制限なく作れます。小説の原稿・設定資料を管理するだけなら、無料プランで十分です。

  • 非公開・公開の保管場所（リポジトリ）を作れる
  • 変更の履歴を確認できる
  • 一部の高度な機能は、非公開の保管場所では使えなかったり、有料プランが必要だったりします（このサイトの手順では使いません）

プランの内容は変わることがあります。最新の情報は GitHub公式ドキュメント（GitHubのプラン）↗ をご確認ください。
