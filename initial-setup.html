ClaudeとGitHubではじめる小説管理

小説の初期設定

このページでやること

  1. 初回プロンプトを送って、サンプルを消し、作品の情報を登録する
  2. （おすすめ）過去作を渡して、自分の文体を覚えてもらう

目安：10〜15分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

テンプレートは現在準備中のため、プロンプトの文面や Claude の作業内容は、今後変わることがあります。

初期設定で Claude がすること知っておくと安心

テンプレートの CLAUDE.md（Claude 用のルール）に従って、次の作業をします。

  • 削除するサンプルファイルの一覧を見せて、あなたに確認する
  • 許可を得てから、サンプルの原稿・プロット・スピンオフを削除する
  • 設定資料を、あなたの作品用の空のひな形にして、伝えた情報を書き込む
  • 作業内容を報告する

1. 初回プロンプトを送る

  1. Claude Code ↗ を開き、小説のリポジトリを選びます。

  2. 下の初回プロンプトを コピー して、Claude Code の入力欄に貼り付けます。

  3. 【 】の部分を自分の作品の内容に書き換えて、送信します。

    【 】の記号ごと消して書き換えてください。決まっていない項目は空欄のままで大丈夫です。設定はあとからいくらでも追加できます。

  4. Claude が削除するファイルの一覧を見せてきたら、確認して次のように返信します。

    一覧のファイルを削除してOKです。進めてください。

  5. Claude の報告を待ち、作業内容を main に反映します。

    反映の方法は 「作業内容の保存と反映」を参照してください。

初期設定がうまくいったか確かめたいとき

次のプロンプトで、今のファイル構成を説明してもらえます。サンプル作品の名前が残っていないか確認しましょう。

2.（おすすめ）自分の文体を覚えてもらう

過去に書いた作品を「文体サンプル」として渡すと、Claude があなたの語り口を参考にして書きます。

  1. 過去作から、文体がよく出ている部分をコピーします（1〜2話ぶん、数千字程度）。

  2. 下のプロンプトの【 】に過去作を貼り付けて送信します。

  3. 続けて下のプロンプトを送り、分析結果がよければ「反映してOKです」と返信します。

  • 文体サンプルは settings/style_samples/ に保存され、Claude は執筆のたびに参考にします。
  • Claude が文体サンプルを書き換えたり、文章や登場人物を新しい原稿にそのまま使ったりすることはありません。
  • サンプルが長いほど Claude の利用量が増えるので、抜粋がおすすめです。
