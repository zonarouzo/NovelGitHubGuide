ClaudeとGitHubではじめる小説管理

小説の初期設定

このページでやること

  1. （おすすめ）過去作を渡して、自分の文体を覚えてもらう
  2. 初回プロンプトを送って、サンプルを消し、作品の情報を登録する
  3. （書いてある原稿がある人）原稿を取り込む
  4. 最後に main に反映する

目安：15〜30分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

テンプレートは現在準備中のため、プロンプトの文面や Claude の作業内容は、今後変わることがあります。

はじめに、Claude Code ↗ を開いて、小説のリポジトリを選んでおきます。このページの作業は、すべて同じ会話の中で続けて行えます。

1.（おすすめ）自分の文体を覚えてもらう

過去に書いた作品を「文体サンプル」として先に渡しておくと、次の初期設定で Claude があなたの文体をルールにまとめ、執筆のときに参考にします。

  1. 過去作から、文体がよく出ている部分をコピーします（1〜2話ぶん、数千字程度）。

  2. 下のプロンプトの【 】に過去作を貼り付けて送信します。

    複数の作品を渡したいときは、1作品ずつ送ってください。

文体サンプルについて知っておくと安心
  • 文体サンプルは settings/style_samples/ に保存され、Claude は執筆のたびに参考にします。
  • Claude が文体サンプルを書き換えたり、文章や登場人物を新しい原稿にそのまま使ったりすることはありません。
  • サンプルが長いほど Claude の利用量が増えるので、抜粋がおすすめです。
  • 文体サンプルは、あとからいつでも追加できます。

2. 初回プロンプトを送る

  1. 下の初回プロンプトを コピー して、Claude Code の入力欄に貼り付けます。

  2. 【 】の部分を自分の作品の内容に書き換えて、送信します。

    【 】の記号ごと消して書き換えてください。決まっていない項目は空欄のままで大丈夫です。設定はあとからいくらでも追加できます。

  3. Claude が削除するファイルの一覧を見せてきたら、確認して次のように返信します。

    一覧のファイルを削除してOKです。進めてください。

  4. 文体サンプルを渡した場合は、文体ルールの案が示されます。内容がよければ「反映してOKです」と返信します。

初期設定で Claude がすること・うまくいったか確かめる方法
  • 削除するサンプルファイルの一覧を見せて、あなたに確認する
  • 許可を得てから、サンプルの原稿・プロット・スピンオフを削除する
  • 設定資料を、あなたの作品用の空のひな形にして、伝えた情報を書き込む
  • 文体サンプルがあれば、文体ルールの案を作って確認する

次のプロンプトで、今のファイル構成を説明してもらえます。

3.（書いてある原稿がある人）原稿を取り込む

途中まで書いてある作品も、このリポジトリで続きから管理できます。書いてある話を1話ずつ貼り付けて保存してもらいます。

  1. 下のプロンプトの【 】を書き換え、原稿を貼り付けて送信します。これを話の数だけくり返します。

    「完成原稿として保存して」とはっきり書いた原稿は、完成原稿として保存されます。まだ直す予定の話は「第一稿」にしておきましょう。本文は一字一句そのまま保存されます。

  2. 全部取り込んだら、下のプロンプトで設定資料とプロットの案を作ってもらいます。案を見て、よければ「保存してOKです」と返信します。

話数が多くて、1話ずつ貼り付けるのが大変なとき（ファイルをまとめてアップロード）

原稿が .txt ファイルになっている場合は、GitHub の画面からまとめてアップロードできます。

  1. 先に、ここまでの作業を main に反映しておきます（4. の手順）。
  2. GitHub で小説のリポジトリを開き、novels → drafts フォルダを開きます。
  3. Add file → Upload files を選び、原稿ファイルをまとめてドラッグして入れます。
  4. 画面下の Commit changes を押して保存します。
  5. Claude Code で新しく会話を始め、下のプロンプトで整理してもらいます（ファイル名の付け直しなど）。

ボタンの表記は変わることがあります。Word などの .txt 以外のファイルは、テキストとして貼り付けるか .txt で保存し直してください。文字化けしている場合は、Claude が変換してよいか確認してきます。

4. 最後に main に反映する

Claude の報告を確認したら、作業内容を main に反映します。方法は 「作業内容の保存と反映」を見てください。

原稿をまとめてアップロードした場合は、アップロードした時点で main に保存されています。そのあと Claude に整理してもらった内容は、反映が必要です。
