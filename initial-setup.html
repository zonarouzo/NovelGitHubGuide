ClaudeとGitHubではじめる小説管理

小説の初期設定

このページでやること

  1. Claude の質問に答えて、サンプルを消し、作品の情報を登録する
  2. （書いてある原稿がある人）原稿を取り込む

目安：10〜30分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

1. Claude の質問に答える

ステップ3で接続を確かめると、Claude が「初期設定」を提案して、いくつか質問してきます。同じ会話のまま、質問に答えていきます。

  1. 削除するサンプルの一覧が示されたら、「消してOKです」と答えます。

  2. 作品の情報（作品名・ジャンル・主人公など）を、わかる範囲で答えます。

    決まっていない項目は空欄で大丈夫です。設定はあとからいくらでも追加できます。

  3. （おすすめ）過去に書いた文章があれば、会話に貼り付けます。

    文体の手本（文体サンプル）として保存され、Claude はあなたの語り口を参考にして書くようになります。1〜2話ぶん（数千字程度）の抜粋で十分です。

  4. 文体ルールの案などを確認されたら、内容を見て「反映してOKです」と答えます。

  5. Claude の報告の「保存の状況」に「main に反映しました」とあれば完了です。

Claude が初期設定を提案してこないとき・新しい会話で始めるとき

次の文章を送ると、初期設定が始まります。【 】の部分を書き換えてから送ってください（【 】の記号ごと消します）。

初期設定で Claude がすること・うまくいったか確かめる方法
  • 削除するサンプルファイルの一覧を見せて、あなたに確認する
  • 許可を得てから、サンプルの原稿・プロット・スピンオフを削除する
  • 設定資料を、あなたの作品用の空のひな形にして、伝えた情報を書き込む
  • 文体サンプルがあれば保存し、文体ルールの案を作って確認する
  • 作業内容を、GitHub のメインの保存場所（main）に反映する

次のプロンプトで、今のファイル構成を説明してもらえます。

文体サンプルについて知っておくと安心
  • 文体サンプルは settings/style_samples/ に保存され、Claude は執筆のたびに参考にします。
  • Claude が文体サンプルを書き換えたり、文章や登場人物を新しい原稿にそのまま使ったりすることはありません。
  • サンプルが長いほど Claude の利用量が増えるので、抜粋がおすすめです。
  • 文体サンプルは、あとからいつでも追加できます。

2.（書いてある原稿がある人）原稿を取り込む

途中まで書いてある作品も、このリポジトリで続きから管理できます。書いてある話を1話ずつ貼り付けて保存してもらいます。

  1. 下のプロンプトの【 】を書き換え、原稿を貼り付けて送信します。これを話の数だけくり返します。

    「完成原稿として保存して」とはっきり書いた原稿は、完成原稿として保存されます。まだ直す予定の話は「第一稿」にしておきましょう。本文は一字一句そのまま保存されます。

  2. 全部取り込んだら、下のプロンプトで設定資料とプロットの案を作ってもらいます。案を見て、よければ「保存してOKです」と返信します。

話数が多くて、1話ずつ貼り付けるのが大変なとき（ファイルをまとめてアップロード）

原稿が .txt ファイルになっている場合は、GitHub の画面からまとめてアップロードできます。

  1. GitHub で小説のリポジトリを開き、novels → drafts フォルダを開きます。
  2. Add file → Upload files を選び、原稿ファイルをまとめてドラッグして入れます。
  3. 画面下の Commit changes を押して保存します。
  4. Claude Code で新しく会話を始め、下のプロンプトで整理してもらいます（ファイル名の付け直しなど）。

ボタンの表記は変わることがあります。Word などの .txt 以外のファイルは、テキストとして貼り付けるか .txt で保存し直してください。文字化けしている場合は、Claude が変換してよいか確認してきます。

作業内容は、Claude が作業のたびに自動で main（メインの保存場所）に反映します。あなたが保存の操作をする必要はありません。
