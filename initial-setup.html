ClaudeとGitHubではじめる小説管理

小説の初期設定

Claude に最初の指示（初回プロンプト）を送って、テンプレートをあなたの作品用に整えます。

🛠 この手順は、テンプレートの完成にあわせて調整します

小説管理テンプレートは現在準備中です。初回プロンプトの文面や、Claude が行う作業の内容は、テンプレートの最終的な仕様にあわせて変わることがあります。

初期設定でClaudeがすること

テンプレートの CLAUDE.md（Claude 用のルール）には、初期設定の手順が書かれています。初回プロンプトを送ると、Claude はそれに従って次の作業をします。

  • サンプル作品のファイルのうち、削除するものの一覧を見せて、あなたに確認する
  • 許可を得てから、サンプルの原稿・プロット・スピンオフを削除する
  • 設定資料（キャラクター・世界観など）を、あなたの作品用の空のひな形にする
  • あなたが伝えた作品の情報（タイトル・あらすじなど）を書き込む
  • 作業内容をわかりやすく報告する

事前に決めておくこと

次の項目を、わかる範囲で考えておきましょう。決まっていない項目は空欄のままで大丈夫です。あとから Claude に頼んで追加できます。

  • 作品タイトル（仮でもOK）
  • ジャンル
  • あらすじ（2〜3行）
  • 主人公（名前・年齢・性格など）
  • 舞台（時代・場所など）
  • 文体（一人称・三人称、です・ます調か常体か など）

文体は、言葉で説明するかわりに過去に書いた作品を見本として渡すこともできます（下の手順）。

手順

  1. Claude Code ↗ を開き、小説管理リポジトリを選びます（ステップ3と同じ操作です）。

  2. 次の「初回プロンプト」の コピー ボタンを押して、文章をコピーします。

  3. Claude Code の入力欄に貼り付けます（パソコンでは Ctrl＋V、Mac では ⌘＋V）。

  4. 【 】の部分を、あなたの作品の内容に書き換えます。【 】の記号ごと消して書き換えてください。

  5. 送信します。

  6. Claude が「削除してよいファイルの一覧」を見せて確認してきます。内容を見て、問題なければ次のように返信します。

    一覧のファイルを削除してOKです。進めてください。

  7. Claude が作業を終えて報告するまで待ちます。報告に「確認してほしいこと」があれば、答えてください。

  8. 作業内容を「main（メインの保存場所）」に反映します。方法は 執筆と管理のページの「作業内容の保存と反映」を参照してください。

自分の文体を覚えてもらう（おすすめ）

過去に書いた作品があれば、それを「文体サンプル」として渡しておくと、Claude があなたの語り口や文のリズムを参考にして書いてくれます。初期設定のあとに行うのがおすすめです。

  1. 過去作の中から、文体がよく表れている部分を選び、コピーします。1〜2話ぶん（数千字程度）で十分です。

  2. 次のプロンプトをコピーして Claude Code に貼り付け、【 】の部分に過去作の文章を貼り付けて送信します。

  3. 保存が終わったら、文体の特徴をルールにまとめてもらいます。Claude が分析結果を見せて確認してくるので、内容がよければ「反映してOKです」と返信します。

ℹ️ 文体サンプルについて

  • 文体サンプルは settings/style_samples/ フォルダに保存され、Claude は執筆のたびに参考にします。
  • 文体サンプルは「読むだけの資料」で、Claude が書き換えたり消したりすることはありません。
  • サンプルの文章や登場人物が、新しい原稿にそのまま使われることはありません。
  • サンプルが長いほど、Claude の利用量も多くなります。全文ではなく抜粋がおすすめです。

初期設定が終わったか確かめる

次のプロンプトを送ると、今のファイル構成を説明してもらえます。サンプル作品の名前が残っていないか確認しましょう。

💡 設定はあとからいくらでも追加できます

初期設定で全部を決める必要はありません。執筆しながら「このキャラクターを設定に追加して」と頼めば、少しずつ資料が充実していきます。

このページのまとめ

  • 初回プロンプトを送り、サンプルを削除した
  • 作品の基本情報を登録した
  • （おすすめ）過去作を文体サンプルとして渡した
  • 作業内容を main に反映した
