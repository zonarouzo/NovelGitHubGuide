目安：10分　／　小さい文字の「補足」と、▶ で開く説明は読み飛ばしてもOKです。

Claude Code とは？ ふつうのチャットとの違いは？知っておくと安心

Claude Code は、Claude がファイルを直接読んだり、書いたり、保存したりできる作業モードです。ブラウザ版では、クラウド上の作業スペースにあなたのリポジトリを取り込んで作業します。公式ドキュメントでは、Pro・Max などのプランで利用できると案内されています。

ふつうのチャットClaude Code
ファイル自分で貼り付けるClaude が自分で読む
書いた文章会話に表示されるだけファイルとして作成・修正
保存自分でコピーして保存Claude が GitHub に保存

どちらも同じアカウントで使え、利用量はプランの上限を共有します。参考：Claude Code 公式ドキュメント（英語）↗

1. Claude Code を開く

  1. claude.ai/code ↗ を開き、Claude Pro のアカウントでログインします。

    スマホでは、Claude のアプリの Code の画面から、新しいセッションを始めます。

2. GitHub とつなぐ

  1. 画面の案内に従って GitHub との連携を始め、GitHub の許可のページで許可します。

    許可が終わると Claude Code の画面に戻ります。

  2. 許可の設定ページ（GitHub）↗を開き、「Repository access」で次の ①〜③ を操作します。

    • ①All repositories（すべてのリポジトリ）か、
    • ②Only select repositories（選んだリポジトリだけ）のどちらかを選びます（選び方は下）。②の場合は、表示される欄で小説のリポジトリを選びます。
    • ③Save（保存）を押します。

    この手続きは「Claude GitHub App のインストール」と呼ばれますが、パソコンやスマホに何かを入れるものではありません。GitHub のページ上で設定するだけです。非公開のリポジトリを使うには、この設定が必要です。

    画像は、すでに設定済みの内容を変更する画面です。はじめて設定する場合は、保存のボタンの名前が違うことがあります（例：Install）。

①と②、どちらを選ぶ？

GitHub を小説専用に使うなら ① All repositories（すべてのリポジトリ）がおすすめです。今あるリポジトリだけでなく、これから作るリポジトリにも自動で許可されるので、作品ごとにリポジトリを増やしても追加の設定がいりません。

GitHub で小説以外の大事なもの（仕事など）も管理している場合は、② Only select repositories にして、小説のリポジトリだけを選んでください。その場合、作品のリポジトリを増やすたびに、この設定ページで追加が必要です。

どちらを選んでも、Claude が作業するのは Claude Code の画面で選んだリポジトリだけです。設定はあとから変更できます。

3. リポジトリを選んで確かめる

  1. パソコンのブラウザでは、次の ①② の順に操作して、小説のリポジトリを選びます。

    • ①入力欄の下にある、本のアイコンのボタン（リポジトリ名）を押します。
    • ②一覧から、ステップ2で作った自分の小説のリポジトリ（画像では my-novel）を選びます（✓ が付きます）。

    リポジトリが多いときは、上の検索欄に名前を入力すると見つけやすくなります。画像では、ほかのリポジトリ名をぼかしています。

    右隣の main（作業の元にする場所）は、そのままで大丈夫です。

  2. スマホのアプリでは、次の ①〜③ の順に操作して、小説のリポジトリを選びます。

    • ①入力欄の上にある リポジトリを追加 を押します。
    • ②一覧から、ステップ2で作った小説のリポジトリを押します。「選択済み」に表示され、✓ が付きます。
    • ③左上の ✕ を押して、一覧を閉じます。

    一覧に見つからないときは、下の さらに接続 から、画面の案内に従って Claude に許可するリポジトリを追加します。画像では、ほかのリポジトリ名をぼかしています。

  3. 次の文章をコピーして送ります。ファイルの一覧が返ってくれば成功です。

    このリポジトリにあるフォルダとファイルの一覧を教えてください。
ファイルは変更しないでください。

    一覧に CLAUDE.md、settings、novels などが出てくればOKです。ブラウザのタブを閉じても、Claude の作業は止まりません。

  4. Claude が「初期設定」を提案してきたら、同じ会話のまま次のページへ進みます。

うまくいかないとき

リポジトリの一覧に、自分の小説リポジトリが出てこない

Claude にそのリポジトリの使用が許可されていない可能性があります。

  1. 許可の設定ページ（GitHub）↗を開きます。
  2. 自分のアカウントを選び、小説のリポジトリが許可に含まれているか確認します。なければ追加して保存します。
  3. Claude Code の画面を再読み込みします。
「Claude Code isn't available on your account」と表示される

Claude Pro（または上位プラン）のアカウントでログインしているか確認してください。会社などの組織アカウントの場合は、管理者の設定が必要なことがあります。

GitHub の許可の画面でエラーになる・途中で止まった

GitHub に正しいアカウントでログインしているか確認し、Claude Code のページを開き直して連携をやり直してください。
