Claude Code とは

Claude Code は、Claude がファイルを直接読んだり、書いたり、保存したりできる作業モードです。ブラウザ版では、Anthropic（Claude の提供元）が用意したクラウド上の作業スペースに、あなたの GitHub のリポジトリを取り込んで作業します。

Anthropic の公式ドキュメントでは、ブラウザ版の Claude Code は Pro・Max などのプランで利用できると案内されています。

参考：Claude Code 公式ドキュメント（英語）↗

ふつうの Claude チャットとの違い

ふつうのチャット（claude.ai）Claude Code
ファイル自分で貼り付けたりアップロードしたりするリポジトリのファイルを Claude が自分で読む
書いた文章会話の中に表示されるだけファイルとして作成・修正できる
保存自分でコピーして保存するClaude が GitHub に保存する
向いていること相談・アイデア出し原稿や設定資料の作成・整理・管理

どちらも同じ Claude のアカウントで使えます。利用量はプランの利用上限を共有します。

Claude Code を開く

  1. パソコンのブラウザで、Claude Code のページを開きます。

    claude.ai/code を開く ↗

  2. Claude Pro を契約しているアカウントでログインします。

GitHub と連携する

はじめて開いたときは、GitHub との連携を求められます。

  1. 画面の案内に従って、GitHub との連携を始めます。GitHub の「許可（認可）」のページが開きます。

  2. 内容を確認して許可します。終わると Claude Code の画面に戻ります。

  3. GitHub の中で、Claude にリポジトリへの出入りを許可します。非公開（Private）のリポジトリで作業するには、この許可が必要です。

    手続きの名前は「Claude GitHub App のインストール」ですが、パソコンやスマホに何かを入れるものではありません。GitHub のページ上で「Claude がどのリポジトリを使ってよいか」を設定するだけです。

    許可の設定ページ（GitHub）を開く ↗

  4. 許可するリポジトリの範囲を選び、画面の案内に従って保存します。どちらを選ぶかは、下の表を参考にしてください。

どのリポジトリを許可する？

All repositories
すべてのリポジトリ

向いている人：GitHub を小説のためだけに使う人。複数の作品をそれぞれのリポジトリで管理する人。

注意点：新しく作ったリポジトリも、自動で Claude が使えるようになります。小説以外の大事なリポジトリがある場合は、それも対象になります。

Only select repositories
選んだリポジトリだけ

向いている人：GitHub で小説以外のもの（仕事・ほかの活動など）も管理している人。

注意点：作品のリポジトリを増やすたびに、この設定ページで追加が必要です。

💡 迷ったら

この GitHub アカウントを小説専用に使うなら、All repositories が手間がかからずおすすめです。どちらを選んでも、あとから設定ページで変更できます。

どちらの場合も、Claude が作業するのは、あなたが Claude Code の画面で選んだリポジトリです。

Pro プランでは、作業用の環境（Default）が自動で用意されると案内されています。特別な設定は不要です。

リポジトリを選ぶ

  1. Claude Code の画面で、文字を入力する欄の近くにあるリポジトリの選択欄をクリックします。

  2. 一覧から、ステップ2で作った小説管理リポジトリを選びます。

  3. ブランチ（作業の元にする場所）の選択欄がある場合は、main のままにします。

つながったか確かめる

次の文章をコピーして Claude Code に送ってみましょう。ファイルを変更せずに、中身の一覧を答えてもらうだけの指示です。

このリポジトリにあるフォルダとファイルの一覧を教えてください。
ファイルは変更しないでください。

CLAUDE.md、settings、novels、spinoffs などが一覧に出てくれば、連携は成功です。

ℹ️ 会話ごとに「セッション」ができます

Claude Code では、依頼ごとに「セッション」（ひとまとまりの作業）が作られます。ブラウザのタブを閉じても、作業は止まらずに続きます。

うまくいかないとき

リポジトリの一覧に、自分の小説リポジトリが出てこない

非公開のリポジトリは、GitHub の設定で Claude にそのリポジトリへの許可（Claude GitHub App のインストール）がされている場合だけ表示されます。

  1. 許可の設定ページ（GitHub）↗を開きます。
  2. 自分のアカウントを選び、許可するリポジトリに小説のリポジトリが含まれているか確認します。含まれていなければ追加して保存します。
  3. Claude Code の画面を再読み込みして、もう一度選択欄を確認します。
「Claude Code isn't available on your account」と表示される

使っているアカウントやプランで Claude Code が使えない状態です。Claude Pro（または上位プラン）を契約しているアカウントでログインしているか確認してください。会社などの組織アカウントの場合は、管理者の設定が必要なことがあります。

GitHub の許可の画面でエラーになる・途中で止まった

GitHub に正しいアカウントでログインしているか確認してから、Claude Code のページを開き直して、連携をやり直してください。二段階認証のコードを求められた場合は、認証アプリの数字を入力します。

そのほかの困りごとは よくある質問・トラブル解決 をご覧ください。
