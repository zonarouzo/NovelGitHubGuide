料金・安全性

GitHub は無料で使える？

はい。個人向けの無料プラン（GitHub Free）で、非公開のリポジトリを数の制限なく作れます。このサイトの手順は無料プランで進められます。

Claude Code を使うには、Claude 側の有料プラン（Claude Pro など）が必要です。

プランの内容は変わることがあります。GitHub公式のプラン説明 ↗

原稿は他人に見られない？

リポジトリを Private（非公開）で作っていれば、あなたと、あなたが許可した人やサービスだけがアクセスできます。Claude Code は、あなたが Claude GitHub App で許可したリポジトリにアクセスします。

リポジトリ名の横に「Private」と表示されているか確認してください。「Public」になっていたら、リポジトリの Settings の下のほうにある「Danger Zone」から変更できます。

アカウントを乗っ取られないか心配

GitHub の二段階認証を設定し、リカバリーコードを安全な場所に保管してください。パスワードはほかのサービスと使い回さないようにしましょう。

Claude の使い方

Claude の利用制限に達したら？

Claude Code の利用量は、ふつうの Claude チャットと同じプランの利用上限に含まれます。上限に達すると、しばらく使えなくなります。

  • 画面に表示される、再び使えるようになる時刻まで待ってください。
  • それまでに保存（反映）された原稿は、GitHub に残っているので消えません。
  • 長い原稿を一度にたくさん書いてもらうと、利用量が増えやすくなります。1話ずつ頼むのがおすすめです。
Claude との会話を新しくしても大丈夫？

大丈夫です。原稿や設定は GitHub に保存されていて、Claude は新しい会話でもそれを読んで作業します。会話の内容そのものは引き継がれないので、必要なことは改めて伝えてください。

注意：前の会話の作業内容を main に反映していないと、新しい会話では前回の変更が見えないことがあります。新しい会話を始める前に、反映をすませておきましょう。

新しい会話の最初に、次のように頼むと状況を確認できます。

別のパソコンやスマホでも使える？

使えます。原稿は GitHub に、作業は Claude のクラウド上にあるので、どのパソコンでも、ブラウザで GitHub と Claude にログインすれば同じように作業できます。

Anthropic の案内では、Claude のスマホアプリからも Claude Code の作業を始めたり、様子を確認したりできるとされています。ただし、このサイトの手順はパソコンでの操作を前提にしています。

複数の作品（別の作品世界）を管理したい

本編とスピンオフは1つのリポジトリでまとめて管理できます。設定を共有しない別の作品世界を書く場合は、ステップ2の手順でテンプレートからもう1つリポジトリを作るのがおすすめです。

Claude への許可を All repositories（すべてのリポジトリ）にしていれば、新しいリポジトリもすぐに Claude Code で選べます。「選んだリポジトリだけ」にしている場合は、許可の設定ページで新しいリポジトリを追加してください。

自分の文体で書いてもらえる？

はい。過去に書いた作品の一部を「文体サンプル」として渡すと、Claude はそれを参考にして書きます。手順は 小説の初期設定の「自分の文体を覚えてもらう」をご覧ください。

ふつうの Claude チャットで書いた文章を取り込みたい

チャットの文章をコピーして Claude Code に貼り付け、「これを本編の第◯話の第一稿として保存して」と頼んでください。

Claude が勝手に完成原稿を書き換えない？

テンプレートの CLAUDE.md に「完成原稿は明示的な依頼がない限り変更しない」というルールを書いており、Claude はそれに従って作業します。ただし AI は間違えることもあるので、報告の「変更したファイル」は確認するようにしましょう。万一変わってしまっても、履歴から元に戻せます。

トラブル

間違えて原稿を変更してしまったら？

GitHub には変更の履歴が残っているので、前の状態に戻せます。Claude に次のように頼んでください。

もっと前の状態に戻したい場合は、過去の原稿の確認・復元を参照してください。

GitHub への保存に失敗したら？
  1. Claude の報告やエラーの文章を確認します。意味がわからなければ、Claude に説明してもらいましょう。
  1. 保存されているかどうかを Claude に確認してもらい、されていなければ保存し直してもらいます。
  1. GitHub との連携が切れている可能性がある場合は、Claude Code との連携のトラブルを確認してください。
リポジトリが Claude Code の一覧に出てこない

Claude GitHub App が、そのリポジトリに許可されていない可能性があります。Claude Code との連携のトラブルを確認してください。

二段階認証のスマホをなくした・機種変更した

保管しておいたリカバリーコードを使ってログインし、新しいスマホで二段階認証を設定し直してください。機種変更の前に、認証アプリの引き継ぎ方法も確認しておきましょう。

サンプル作品が残ったままになっている

小説の初期設定の初回プロンプトを、もう一度送ってください。

用語

PR（プルリクエスト）やブランチとは何？

ブランチは、リポジトリの中に作る「作業用の保存場所」です。メインの保存場所は main というブランチで、Claude Code は作業ごとに別のブランチを作って、そこに変更を保存することがあります。

PR（プルリクエスト）は、「作業用のブランチの変更を main に取り込みたい」という申請です。PR を「マージ（取り込み）」すると、変更が main に反映されます。

将来的には、利用者が PR やブランチを意識しなくてよい仕組みを目指していますが、現在は準備中です。今の手順は 作業内容の保存と反映 をご覧ください。

.txt と .md の違いは？

.txt は飾りのない文字だけのファイルで、このテンプレートでは小説の本文に使います。.md（マークダウン）は、見出しや表などを使える文章ファイルで、設定資料やプロットに使います。GitHub の画面では、.md は見出しや表が整った状態で表示されます。

CLAUDE.md とは？

Claude が作業するときに守るルールを書いたファイルです。Claude Code は、リポジトリにあるこのファイルを読んでから作業します。ふだんは触る必要はありません。

コミット・プッシュ・マージとは？
  • コミット：変更を「記録」すること
  • プッシュ：記録した変更を GitHub に「保存」すること
  • マージ：別のブランチの変更を「取り込む」こと

これらの操作は Claude が行うので、言葉を覚える必要はありません。

解決しないときは

Claude Code に、困っていることをそのまま書いて相談してみてください。エラーの文章を貼り付けると、原因を説明してもらえます。
