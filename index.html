ClaudeとGitHubではじめる
小説管理

原稿・プロット・設定資料を、Claude と一緒に書いて、整理して、安全に保存する。
GitHub がはじめてでも、ブラウザだけで始められます。

はじめる

必要なもの

  • Claude Pro の契約（Max などの上位プランでもOK）
  • パソコンとブラウザ（Chrome、Edge、Safari など）
  • メールアドレス（GitHub の登録に使います。GitHub は無料です）

パソコンにソフトをインストールする必要はありません。

はじめるまでの流れ

上から順番に進めてください。各ページの最後で「完了」にチェックすると、ここに進み具合が表示されます。

  1. 1. GitHubアカウントの作成
  2. 2. 小説管理リポジトリの作成
  3. 3. Claude Codeとの連携
  4. 4. 小説の初期設定
  5. 5. 小説の執筆と管理

困ったときは よくある質問・トラブル解決、よく使う指示は プロンプト集 へ。

できるようになること

📚

設定を読んでから書いてくれる

保存済みの設定資料や原稿、あなたの過去作の文体を参考に、Claude が執筆を手伝います。

🔒

自分だけの非公開の保管場所

原稿は GitHub の非公開（Private）の場所に保存され、自分以外には見えません。

🕰

変更の履歴が残る

「前のほうが良かった」というときも、確認・復元ができます。

🛡

完成原稿を守るルール

完成原稿は、あなたが指示しない限り Claude が変更しません。本編と複数のスピンオフもまとめて管理できます。

このサイトの現在の状況：小説管理テンプレートは改良を続けているため、手順の細かい部分は今後変わることがあります。
