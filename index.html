ClaudeとGitHubではじめる
小説管理

原稿・プロット・設定資料を、Claude と一緒に安全に書いて、整理して、保存する。
GitHub がはじめての人でも、ブラウザだけで始められます。

はじめる

パソコンへのソフトのインストールは不要です。

このサイトでできるようになること

このサイトの手順を順番に進めると、次のような「小説の仕事場」ができあがります。

  • Claude に日本語で頼むだけで、プロット作り・執筆・推敲を手伝ってもらえる
  • 原稿・プロット・キャラクター設定・世界観設定を、決まった場所に整理して保存できる
  • 本編と複数のスピンオフを、設定を共有しながら管理できる
  • いつ・何を変えたかの履歴が残り、前の状態を確認できる

Claude と GitHub を組み合わせるメリット

📚

設定を読んでから書いてくれる

Claude が保存済みの設定資料やこれまでの原稿を読んでから執筆するので、毎回説明し直す手間が減ります。

🔒

自分だけの非公開の保管場所

GitHub の「非公開（Private）」の保管場所を使うので、原稿は自分以外には見えません。

🕰

変更の履歴が残る

保存するたびに記録が残るので、「前のほうが良かった」というときも確認・復元ができます。

🛡

完成原稿を守るルール

テンプレートには「完成原稿は指示がない限り変更しない」などのルールが入っていて、Claude はそれに従って作業します。

必要なもの

必要なもの説明
GitHub のアカウント（無料）原稿を保管する場所です。ステップ1で作ります。
Claude Pro の契約ブラウザ版の Claude Code を使うために必要です（Max などの上位プランでも使えます）。
パソコンとブラウザChrome、Edge、Safari など。設定作業はパソコンで行うのがおすすめです。
メールアドレスGitHub のアカウント作成と確認に使います。
