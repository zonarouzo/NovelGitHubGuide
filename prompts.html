プロンプト集

Claude Code によく使う指示（プロンプト）をまとめました。コピー ボタンを押して、Claude Code の入力欄に貼り付けて使ってください。

使い方のコツ

  • 【 】の部分は、自分の内容に書き換えます。【 】の記号ごと消してください。
  • 話数は「第3話」のように数字で伝えるとわかりやすくなります。
  • 意見だけほしいときは「ファイルは変更しないでください」と書き添えます。
  • 完成原稿を直すときは「完成原稿の第◯話」と明記します。
  • スピンオフの場合は「スピンオフ『タイトル』の」と作品名を入れます。
  • このとおりの文章でなくても大丈夫です。ふだんの言葉で頼んでも Claude は理解します。
